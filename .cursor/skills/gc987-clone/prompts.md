# 下次直接发给我的短口令

长约束已经写在 `SKILL.md`。不要再贴那份「硬性约束覆盖 Next.js」全文。

## 1. 开机（打开本地 + 线上）

```
开机：打开 987 本地和线上
```

可选补一句路径，默认都是首页：

```
开机：打开 987 本地和线上，开到 /main/withdraw
```

我会：复用或启动 `http://localhost:5987`，Chrome 里开本地 + `https://gc987.com` 两个标签，都切到 390×844 手机模式。线上要登录就停下来等你。

## 2. 更新已有路由

```
更新路由 /main/entrar
1. 输入框提示词太大了
2. 按钮禁用时字体太亮
3. 桌面端左右边距跟源站不一致
```

把 `/main/entrar` 换成目标路径。后面的编号列表可有可无；没有就按源站整页对照。

## 3. 更新页面弹窗 / 覆盖层

```
更新弹窗 首页登录弹窗
1. 国旗位置偏下
2. 记录密码的勾太大
```

弹窗不要写新路由，除非你明确说源站 pathname 变了。

也可以把弹窗和所在页写在一起：

```
更新路由 /main/inicio 的登录弹窗
1. 底部安卓说明只在安卓显示
```

## 4. 克隆还没有的页面或入口

```
克隆：底栏 Saque
从 https://gc987.com/main/inicio 点底栏 Saque
```

或：

```
克隆新页：头栏记录图标
从 https://gc987.com/main/withdraw 点右上角单据
没有接口的用 mock
```

我会先在源站点进去，pathname 变了就建同名路由，没变就做当前页弹层。

## 5. 换到别的站点目录

点名文件夹之后，后面的修改只发生在那个目录里，不会改 gc987。例如：

```
打开 brjornal.com
```

文件夹在仓库根目录。之后直接说要改什么即可。要改回 987，再用上面的开机 / 更新路由 / 更新弹窗。

## 6. 开机后接着改

两件事写在同一条即可：

```
开机：打开 987 本地和线上
然后更新路由 /spread
1. WhatsApp 图标间距不对
```
